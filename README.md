# Mindchain

**Experimental implementation of the VectorRail authorization architecture**

> **AI Decision ≠ Authorization to Execute**

Mindchain is the experimental protocol and engineering foundation behind **VectorRail**, a vendor-neutral authorization and execution-governance architecture for autonomous agents and machines.

## What Mindchain explores

At a high level:

**Intent → Policy Evaluation → Authorization → Admission → Protected Execution → Evidence**

The design is intended to remain model-agnostic, hardware-agnostic, protocol-agnostic, infrastructure-agnostic, domain-agnostic and partner-integrable.

Mindchain is not an AI model, a blockchain, a payment rail or a replacement for existing agent communication standards.

## Current public validation status

**960 deterministic lifecycle tests — PASS**

Validation covers, at an aggregate level, authorization integrity, replay resistance, admission consistency, protected execution, failure handling, durable authority behavior, concurrency and restart scenarios.

Additional focused integration and durability suites are maintained in the private engineering environment.

## Development provenance

Mindchain development began in **January 2026**.

As the project evolved from an experimental MVP toward the broader VectorRail architecture, the complete engineering repository was transitioned to private development in August 2026.

This repository preserves the long-standing public project URL while providing a deliberately limited public reference surface.

See [Development History](docs/DEVELOPMENT_HISTORY.md).

## Public repository scope

This repository shows **what has been built and validated** without publishing the proprietary implementation methods used to achieve those results.

It intentionally excludes the production-oriented core implementation, exhaustive test suites, database internals, failure-injection mechanisms, detailed security architecture and internal engineering context.

Mindchain / VectorRail remains an **experimental, non-production system** under active development.
